# Desktop Draux
An interactive desktop pet that can play ambience sounds. Download and run from [itch.io](https://viywolf.itch.io/desktop-draux).

![Desktop Draux Cover Art](https://github.com/viywolf/Desktop-Pet/blob/main/assets/cover_art.png)

## Features
- The draux stays near the bottom of the screen, walking back and forth and occasionally idling.
- You may pick up and drop the draux anywhere on the screen. Hovering over the draux will cause it to slow down and stop
- Right clicking the draux will make an option menu appear, where you can open the settings or close the program
- Settings menu allows you to play ambience sound, adjust the volume of the sound, disable draux movement, and disable music effects. It is also draggable.

\* A draux is a cat-dragon-other hybrid species (created by me!)

## How does it work?
Desktop Draux was made with Godot 4.7

The windows feature of Godot was used heavily. Not only is the actual draux its own window, the settings menu is also its own window, along with the music note effect (this did significantly limit the number of notes I decided to have on screen at a time since too many windows would lag Godot).
